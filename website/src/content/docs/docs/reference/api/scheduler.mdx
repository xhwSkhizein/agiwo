# Scheduler API

Session product chat uses `MainAgent.accept`. The Scheduler facade is waitset + cancel + persistent-root enqueue.

## Lifecycle

```python
async with Scheduler() as scheduler:
    ...
```

or:

```python
scheduler = Scheduler()
await scheduler.start()
...
await scheduler.stop()
```

## Core methods

### `enqueue_input(...)`

Enqueue user input for a persistent root:

- `IDLE` / `FAILED` → `pending_input` / `QUEUED`
- `RUNNING` → live handle `enqueue_message`
- `WAITING` / `QUEUED` → `USER_HINT` (WAITING is urgent)

### `wait_for(...)`

Wait until a state settles to `IDLE`, `COMPLETED`, or `FAILED`.

### `register_worker_parent(...)`

Register a persistent root that may spawn Workers.

## Control methods

- `cancel(...)`
- `shutdown(...)`
- `rebind_agent(...)`

## Query methods

- `get_state(...)`
- `list_states(...)`
- `list_events(...)`
- `get_stats(...)`
- `get_registered_agent(...)`

## State storage backends

`SchedulerConfig.state_storage.storage_type` supports:

- `memory`
- `sqlite`
